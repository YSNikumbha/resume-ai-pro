# Release Checklist

Use this checklist before cutting a release or starting a live deployment.

- [ ] Backend tests pass
- [ ] Backend package passes
- [ ] Frontend build passes
- [ ] Docker config valid
- [ ] DB healthy
- [ ] Backend healthy
- [ ] Frontend healthy
- [ ] Actuator returns UP
- [ ] pgvector extension enabled
- [ ] No secrets tracked
- [ ] GitHub Actions green
- [ ] Production DB not yet provisioned
- [ ] Backend not yet deployed
- [ ] Frontend not yet deployed
